# 🛴 Финальный проект 6 спринта: Автоматизация тестирования Яндекс.Самокат

## 📋 О проекте

В этом проекте вы закрепите навыки **UI-тестирования**, примените **Page Object Model** и подключите **Allure-отчёт**. Вам предстоит написать автотесты для учебного сервиса «Яндекс.Самокат», разработанного специально для студентов.

---

## 🎯 Задание

Покрыть автотестами сценарии.

### 1. Подготовка проекта

* Установить браузер **Mozilla Firefox**
* Создать новый проект с названием **Sprint_6**
* Подключить зависимости:
  * **Selenium WebDriver**
  * **Allure** (для формирования отчётов)

## 📝 Тестовые сценарии

### 🔽 Раздел «Вопросы о важном» (выпадающий список)

**Что проверить:**  
При нажатии на стрелочку открывается соответствующий текст.

**Требования:**
* Написать **отдельный тест на каждый вопрос**
* Проверить, что текст ответа соответствует ожидаемому

---

### 🛵 Заказ самоката

**Проверить полный позитивный сценарий с двумя наборами данных**

**Точки входа в сценарий (обе должны быть протестированы):**
1. Кнопка «Заказать» в **верхней части** страницы
2. Кнопка «Заказать» в **нижней части** страницы

**Шаги позитивного сценария:**
1. Нажать кнопку «Заказать»
2. Заполнить форму заказа
3. Проверить появление всплывающего окна с сообщением об успешном создании заказа

**Дополнительные проверки:**
* Нажатие на логотип **«Самоката»** ведёт на **главную страницу**
* Нажатие на логотип **Яндекса** открывает в новом окне (через редирект) **главную страницу Дзена**

**Важно:**
* Использовать минимум **два набора данных**
* Сценарий общий для обеих точек входа (не нужно дважды тестировать каждую)

## 🧪 Написание тестов

### Архитектура
* Создать отдельный пакет для **Page Object**
* Для каждой страницы — отдельный класс с Page Object
* Все тесты разместить в директории `tests`

### Организация тестов
* Тесты группировать по **тематике/функциональности**
* Не создавать отдельный класс для каждого теста
* Тесты на одну функциональность объединять в один класс

### Обязательные требования
* Использовать **параметризацию** (найти места для параметризации самостоятельно)
* Проверить, что тесты успешно запускаются
